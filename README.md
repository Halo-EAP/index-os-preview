#  HALOS (Halo Early Access Preview)

> This Project is currently ran by me, myself, and I, but that's okay!
> HalOS is a custom OS based on linux with the purpose of being able to save a lot of battery and lengthen the life of a small battery, its also meant to bring native EXE file support to Mobile Devices( Only Halo Phones unfortunatly) its also soon to have Airpod, Airdrop, And Galaxy Buds Support!

## 🌌 Overview

**HALOS** is an experimental mobile operating system built around modern UI principles, fluid animations, and high-performance desktop environment docking. This repository serves as the official public web portal for early-access updates, system status metrics, release notes, and community feedback.

---

## 🛠 What's Currently Happening?

Currently working on the base UI And GUI mod support for the OS, The Application used for modifying this GUI and such is currently in Beta so its not capable of much, but its usable and supports more customization than current build android (excluding custom launchers).

## What to Expect After?
After The current Application is polished(also meaning that base UI and GUI is polished) I will start working on fusing the GUI and .HUI files for adding support, meaning the current os will be able to understand the .hui files and change its UI to the instructions its told.
